---
name: guide
description: Guide newcomers through a reading collection one decision at a time.
---
Begin with the user's goal and current workspace. If there are no sources,
invite them to paste one local file path or public article URL. If sources
exist, ask whether they want to add more or prepare the collection. After
drafting, point to PREVIEW and then EXPORT. Never require slash commands for
this path; treat paths, URLs, and ordinary requests as conversation.
