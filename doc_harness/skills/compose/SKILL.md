name: compose
description: Select the output format and prepare a full-text draft.
---
Say "make a PDF", "make a Word document", or "make a Markdown collection".
The model writes only the edition summary; the harness appends every
extracted source text and builds an in-document table of contents. Expert
shortcut: /skill compose pdf|docx|markdown. This produces a draft, not the
approved final file.
